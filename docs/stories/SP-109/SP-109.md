## Coordination summary

`apps/web/src` is organized by **file type** (flat `components/`, `pages/`,
`context/`, `hooks/`, `services/`, `store/`, `types/`, `utils/`): every auth
concern is split across eight folders, so a feature change touches files in five
directories. The user asked (2026-10-17) for the frontend to be organized into
feature folders and chose **Feature-Sliced Design** layers.

This parent reorganizes the web app into `app / pages / widgets / features /
entities / shared`, with each feature folder owning its components, hooks,
slice/thunks/selectors and API module. It is a **pure relocation refactor** plus
one narrow structural extraction (`getProfile`/`updateProfile` →
`entities/user/api/userService.ts`, SP-109D) and one config/enforcement pass
(A, I).

Frozen contracts for every child (from the [breakdown README](./README.md)):

- **Behavior is unchanged.** No route, markup, class, validation schema, error
  message, interceptor branch or test assertion is edited. The 193-test suite
  (19 files, green 2026-10-17) is the regression net for all nine children.
- **Transport semantics are untouched** (RD4/RD5): `shared/api/httpClient.ts`
  (was `services/api.ts`) keeps its default export, `refreshAccessToken`,
  `setSessionExpiredHandler`, `AUTH_PATHS`/recovery sanitization and the
  single-flight refresh; `shared/api/recovery.ts` keeps the barrier, generation
  counter and `RecoveryError`.
- **Public auth interface is untouched** (SP-108 RD3): `useAuth`'s
  `AuthContextType` and the RTK slice/thunk names are unchanged by the move —
  only the folder changes.
- **Import direction** follows the README contract; the only sanctioned upward
  imports are the three RTK type imports from `@/app/store` (RD7).

Not in scope (recorded, with owners): splitting the RTK Query API per feature
(RD10 → EP02+ breakdown), relocating the unused academic types out of
`shared/types/academic.ts` (RD9 → EP02 breakdown), any backend/DTO/database
change, any new test framework or dependency beyond the optional
`eslint-plugin-import` devDependency if RD6 needs it, and any visual/a11y or
responsive redesign.

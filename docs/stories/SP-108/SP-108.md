## Coordination summary

The web app currently uses **TanStack Query 5** for server state (verified:
`main.tsx` `QueryClientProvider` + Devtools, `useMutation` in
`hooks/useResendVerification.ts`, four test files wrapping
`QueryClientProvider`) and **React Context** for auth/session state
(`context/AuthContext.tsx`), consumed by 9 components/pages through `useAuth`.

Per the user's 2026-10-16 decisions (RD1/RD2 in the [README](./README.md)):

1. **Redux Toolkit is adopted** and **all** existing client state migrates into
   it — the documented TanStack architecture decision is reversed.
2. **RTK Query replaces TanStack Query entirely**; the dependency is removed.

Fixed cross-child contracts (children must not change these):

- `AuthContextType` (the public `useAuth` interface) stays identical during B —
  consumers untouched; SP-105G session generations/barrier behavior preserved.
- `services/api.ts` axios instance (single-flight refresh, recovery barrier,
  `AUTH_PATHS`, sanitized errors) stays the transport under RTK Query (RD4).

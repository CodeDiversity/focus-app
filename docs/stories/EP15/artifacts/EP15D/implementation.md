## Deviations

1. **Preserved planned rows are read for every date** (F-EP15D-01) rather than only the range the story's seam signature implies — the EP08 counts are the authority.
2. **The seam returns three extra fields** (`days`, `bounds`, `occurrences`) beyond the six in contracts.md, so the calendar can emit `days[]` and the block events (titles, `recurring`, course display fields) without a second pass over the rows. The six contract fields are unchanged.
3. **`gatherPlanData` keeps one planned-session read of its own** for the locked-minutes subtraction. It derives minutes, not intervals, so AC1's "only interval derivation" holds; the busy intervals come from the seam.
4. **The EP13J service energy pins now run on study blocks inside default bounds** (`study-plans-energy.service.spec.ts`): the former available windows are STUDY blocks (NORMAL 09–10 daily, Friday 18–20 with the energy under test). Every expectation held unchanged, which is the EP15C single-tier argument confirmed at the service level.
5. **`legacy-windows.ts` stays in the domain as test support** (identity battery, EP13J pins). Nothing under `src/modules` imports it; the grep assertion pins that.
